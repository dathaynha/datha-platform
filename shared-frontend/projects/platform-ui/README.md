# @datha/platform-ui

Private shared theme package for DatHa Angular frontends.

```typescript
import { platformAuraPreset } from "@datha/platform-ui";
```

```scss
@use "@datha/platform-ui/styles";
```

Consumers must use the exact Angular and PrimeNG peer versions declared by this package. See the repository README for Azure Artifacts authentication, release, and troubleshooting instructions.
